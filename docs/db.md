# DueOne — Database Schema Draft

> Status: Design only. No database implemented yet.
> Target: MySQL 8 / MariaDB 10.6+

---

## users

Stores registered users.

```sql
CREATE TABLE users (
  id          VARCHAR(36)  PRIMARY KEY,          -- UUID
  name        VARCHAR(100) NOT NULL,
  email       VARCHAR(255) NOT NULL UNIQUE,
  password    VARCHAR(255) NOT NULL,             -- bcrypt hash
  avatar_url  VARCHAR(500),
  created_at  DATETIME     NOT NULL DEFAULT NOW(),
  updated_at  DATETIME     NOT NULL DEFAULT NOW() ON UPDATE NOW()
);
```

---

## spaces

Each Space is a private group for 2 to 5 people.

```sql
CREATE TABLE spaces (
  id           VARCHAR(36)  PRIMARY KEY,
  name         VARCHAR(100) NOT NULL,
  type         ENUM('couple','friends','family','study','private') NOT NULL,
  description  VARCHAR(500),
  invite_code  VARCHAR(20)  NOT NULL UNIQUE,     -- used for member joining
  created_at   DATETIME     NOT NULL DEFAULT NOW(),
  updated_at   DATETIME     NOT NULL DEFAULT NOW() ON UPDATE NOW()
);
```

---

## space_members

Join table linking users to spaces. Enforces max 5 members via application logic.

```sql
CREATE TABLE space_members (
  id         VARCHAR(36) PRIMARY KEY,
  space_id   VARCHAR(36) NOT NULL,
  user_id    VARCHAR(36) NOT NULL,
  role       ENUM('owner','member') NOT NULL DEFAULT 'member',
  joined_at  DATETIME NOT NULL DEFAULT NOW(),

  UNIQUE KEY uq_space_user (space_id, user_id),
  FOREIGN KEY (space_id) REFERENCES spaces(id) ON DELETE CASCADE,
  FOREIGN KEY (user_id)  REFERENCES users(id)  ON DELETE CASCADE
);
```

Constraint: application must reject join if space already has 5 members.

## calendar_events

Events within a space's shared calendar.

```sql
CREATE TABLE calendar_events (
  id          VARCHAR(36)  PRIMARY KEY,
  space_id    VARCHAR(36)  NOT NULL,
  title       VARCHAR(200) NOT NULL,
  description TEXT,
  start_at    DATETIME     NOT NULL,
  end_at      DATETIME     NOT NULL,
  visibility  ENUM('all','private') NOT NULL DEFAULT 'all',
  created_by  VARCHAR(36)  NOT NULL,
  created_at  DATETIME     NOT NULL DEFAULT NOW(),
  updated_at  DATETIME     NOT NULL DEFAULT NOW() ON UPDATE NOW(),

  FOREIGN KEY (space_id)   REFERENCES spaces(id) ON DELETE CASCADE,
  FOREIGN KEY (created_by) REFERENCES users(id)  ON DELETE CASCADE,
  INDEX idx_space_start (space_id, start_at)
);
```

## chat_rooms

Each space has exactly one chat room. Created automatically when the space is created.

```sql
CREATE TABLE chat_rooms (
  id         VARCHAR(36)  PRIMARY KEY,
  space_id   VARCHAR(36)  NOT NULL UNIQUE,       -- one room per space
  name       VARCHAR(100) NOT NULL DEFAULT 'Secret Chat',
  created_at DATETIME     NOT NULL DEFAULT NOW(),

  FOREIGN KEY (space_id) REFERENCES spaces(id) ON DELETE CASCADE
);
```

---

## messages

Messages in a chat room.

```sql
CREATE TABLE messages (
  id           VARCHAR(36) PRIMARY KEY,
  chat_room_id VARCHAR(36) NOT NULL,
  sender_id    VARCHAR(36) NOT NULL,
  content      TEXT        NOT NULL,
  created_at   DATETIME    NOT NULL DEFAULT NOW(),
  deleted_at   DATETIME,                         -- soft delete

  FOREIGN KEY (chat_room_id) REFERENCES chat_rooms(id) ON DELETE CASCADE,
  FOREIGN KEY (sender_id)    REFERENCES users(id)      ON DELETE CASCADE,
  INDEX idx_room_created (chat_room_id, created_at)
);
```

---

## Notes

- All primary keys use UUID strings (VARCHAR(36)) for portability.
- `deleted_at` on messages allows soft-delete without losing history.
- Encryption of message content is planned for a future version — `content` may become a BLOB with encrypted bytes.
- The `invite_code` on spaces is a short random token used to invite the 2nd–5th member. It can be regenerated by the owner.
