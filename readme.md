# DueOne Demo

DueOne Demo is an early frontend prototype for a private space app for 2 to 5 close people.

This repository is a demo/prototype version.
It is not the final product architecture.

## Current Scope

- Space list
- Space home
- Shared calendar mock page
- Secret chat mock page
- Mock data only
- Frontend only

## Not Included

- Authentication
- Backend API
- Database connection
- Real-time chat
- Encryption
- Production deployment

## Tech Stack

- Next.js
- TypeScript
- React

## How to Run

npm install
npm run dev

Open http://localhost:3000

## Future Direction

The next version will be redesigned as dueone-core with improved product planning, UX flow, backend structure, and database design.
